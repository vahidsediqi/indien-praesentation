# 10 Tage in Indien – Präsentation B2

Web presentation for our B2 German course (Waheedullah, Etaf, Danylo, Yevhen).

**Live:** https://vahidsediqi.github.io/indien-praesentation/

## Steuerung

| Taste | Aktion |
|---|---|
| → / Leertaste / Klick | nächste Folie |
| ← | zurück |
| F | Vollbild |
| N | Sprechtext ein/aus (zum Üben) |
| ? | Hilfe |

On a phone or tablet: swipe left/right.
